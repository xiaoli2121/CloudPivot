# CloudPivot

CloudPivot is an enterprise-grade open source rapid development platform with frontend-backend separation, low-code enablement, and out-of-the-box foundations for platform vendors and delivery teams.

## Repository Layout

- `cloudpivot-vue3/`: Vue 3 frontend workspace for admin shell, designer studio, runtime app, and shared packages
- `cloudpivot-springboot/`: Spring Boot modular monolith backend skeleton and backend modules
- `cloudpivot-uniapp/`: uni-app mobile application skeleton for future mobile and mini-program support

## Current Bootstrap Scope

This repository currently keeps the workspace intentionally slim at the root level: only the three application projects plus the root `.gitignore` and `README.md`. The next step is to evolve each project into a runnable minimal starter.

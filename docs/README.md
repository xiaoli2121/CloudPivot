# CloudPivot 文档索引

本目录用于沉淀 CloudPivot 的产品设计、总体架构、模块设计与阶段实施计划，作为社区版 1.0 的统一设计基线。

## 文档清单

- `产品定位.md`：产品愿景、目标用户、核心价值与版本边界
- `总体架构.md`：平台整体分层、部署形态与核心链路
- `核心模块设计.md`：社区版核心模块职责、边界与协同关系
- `技术架构选型.md`：前后端、认证、中间件与数据库技术选型
- `认证与权限设计.md`：基于 Shiro 的认证授权模型与接口流程
- `数据库设计规范.md`：MySQL 主库、兼容 PostgreSQL 的建模与 SQL 规范
- `前端架构设计.md`：Vue3 前端工程分层、应用划分与交互骨架
- `后端架构设计.md`：Spring Boot 模块化单体设计与分层约束
- `低代码引擎设计.md`：元数据驱动、设计态与运行态核心设计
- `插件体系设计.md`：插件模型、扩展点与生命周期机制
- `产品路线图.md`：从社区版 1.0 到增强版本的演进路径
- `社区版1.0实施计划.md`：社区版 1.0 的目标、阶段、交付与验收

## 当前设计基线

- 产品定位：企业级前后端分离开源快速开发平台
- 目标特征：低代码赋能、开箱即用、支持二开与插件扩展
- 认证方案：Apache Shiro
- 数据库策略：MySQL 为主，兼容 PostgreSQL
- 交付目标：优先落地社区版 1.0 的可运行、可扩展、可二次开发基础底座

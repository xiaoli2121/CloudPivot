# CloudPivot 技术架构选型

## 1. 选型原则

CloudPivot 的技术架构选型围绕以下原则展开：

- 成熟稳定：优先采用社区成熟、长期可维护的技术
- 易于交付：优先兼顾开发效率、学习成本和私有化部署便利性
- 面向扩展：为低代码、插件化和后续分布式演进保留空间
- 兼容务实：数据库以 MySQL 为主，同时兼容 PostgreSQL

## 2. 前端技术选型

### 2.1 核心框架

- 框架：Vue 3
- 语言：TypeScript
- 构建工具：Vite
- 路由：Vue Router
- 状态管理：Pinia

选择原因：

- Vue 3 生态成熟，适合后台系统和设计器类应用
- TypeScript 便于维护复杂元数据结构与可视化配置模型
- Vite 启动快，适合多应用工作区开发模式

### 2.2 组件与交互层

- UI 组件库：Element Plus
- 图表能力：ECharts
- 富文本与代码编辑：Monaco Editor、按需引入编辑器能力
- HTTP 请求：Axios 或统一封装请求 SDK

选择原因：

- Element Plus 适合企业后台管理场景
- 图表与可视化能力利于工作台和分析类页面扩展
- 代码编辑器适合设计器表达式、脚本和模板配置场景

### 2.3 前端工程模式

- 工作区模式：多应用 + 多共享包
- 应用划分：管理后台、设计器、运行容器、门户
- 共享能力：UI、SDK、类型定义、工具方法、设计器核心、运行时引擎

## 3. 后端技术选型

### 3.1 核心框架

- JDK：Java 21
- 框架：Spring Boot 3.x
- Web：Spring MVC
- 构建工具：Maven

选择原因：

- Java 21 具备长期维护优势，语言特性更现代
- Spring Boot 3 生态成熟，便于快速构建企业应用
- 模块化单体形态更适合社区版快速落地

### 3.2 认证与安全

- 认证框架：Apache Shiro
- 认证模式：前后端分离下的 Token/JWT 认证
- 会话增强：Redis 存储登录状态、黑名单或刷新控制信息

选择原因：

- Shiro 轻量、清晰，适合快速开发平台做定制化认证授权实现
- 能较好支持菜单权限、按钮权限、接口权限和数据权限扩展

### 3.3 数据访问层

- ORM/持久化：MyBatis-Plus
- SQL 管理：XML + 注解结合，复杂场景保留显式 SQL 能力
- 分页与基础查询：使用统一数据访问规范封装

选择原因：

- MyBatis-Plus 适合后台管理与平台型项目快速开发
- 保留原生 SQL 可控性，更适合复杂元数据与权限查询场景

## 4. 数据库与存储选型

### 4.1 主数据库

- 主数据库：MySQL
- 兼容数据库：PostgreSQL

策略说明：

- 社区版默认以 MySQL 作为主流部署方案
- 所有表结构设计、字段命名和 SQL 写法均需兼容 PostgreSQL
- 避免深度依赖某一数据库方言特性

### 4.2 缓存与辅助存储

- 缓存：Redis
- 文件存储：本地文件系统，预留对象存储适配能力
- 日志存储：默认文件日志，预留对接 ELK 等方案的能力

## 5. 低代码与扩展相关选型

### 5.1 元数据承载

- 业务对象、页面定义、表单布局、组件配置统一采用元数据存储
- 优先以数据库表承载核心元数据，必要时补充 JSON 配置结构

### 5.2 规则与流程

- 社区版 1.0 以接口与模块预留为主
- 流程、规则、编排能力在后续版本中逐步增强

### 5.3 插件机制

- 后端：基于 Spring Boot 模块与 SPI/注册表实现插件接入
- 前端：基于动态路由、组件注册和扩展点机制实现插件装配

## 6. 运维与工程规范选型

- 配置文件：YAML
- 单元测试：JUnit 5、Spring Boot Test
- 前端测试：Vitest、Vue Test Utils
- 代码风格：统一 ESLint/Prettier 与 Java 代码规范
- 脚本支持：Windows 下提供 BAT 脚本，后续补充 Shell 脚本

## 7. 不优先采用的方案

社区版 1.0 阶段，以下方向不作为优先技术落地方案：

- 直接上微服务全家桶
- 复杂的服务网格或分布式事务体系
- 强依赖单一数据库专属能力的设计
- 过度重量级的工作流或规则平台集成

## 8. 技术选型结论

CloudPivot 社区版 1.0 的推荐技术基线为：

- 前端：Vue 3 + TypeScript + Vite + Pinia + Vue Router + Element Plus
- 后端：Java 21 + Spring Boot 3.x + Spring MVC + MyBatis-Plus
- 认证：Apache Shiro
- 数据库：MySQL 为主，兼容 PostgreSQL
- 缓存：Redis

这套组合兼顾了快速开发、平台扩展、二开友好和私有化部署便利性，符合 CloudPivot 当前阶段的产品目标。
